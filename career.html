About the Role

You'll architect and build the APIs that power ZyloHub. Real-time job matching, payment processing, worker verification – it all runs on your code. You'll work in a fast-paced environment where your decisions directly impact millions of users.

What You'll Do

  • Design and develop scalable REST APIs using Node.js and Express
  • Work with MongoDB for database design and optimization
  • Implement authentication, authorization, and security best practices
  • Integrate payment gateways (Razorpay) and third-party services
  • Deploy and monitor applications on cloud platforms (Google Cloud)

What You Need

Node.js (2+ years) Express.js MongoDB REST API Design JWT/OAuth Git & CI/CD

Nice to Have

WebSockets Microservices Payment Integration Google Cloud
